A program that draws one newspaper front page summing up the world news of Friday 20 November 2026: Russia launches a major overnight missile attack on Kyiv and hits three bridges across the Dnipro; Germany rejects a new Yalta deal after the Shenzhen summit and the EU meets the UK in Brussels; COP31 drops the call to phase out fossil fuels; a Houthi missile damages a tower in Riyadh and a tanker hits a mine in the Strait of Hormuz; markets fall for a fifth straight day; and Israel crosses the Yellow Line ceasefire boundary in central Gaza.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

Pure Python standard library only: no network, no randomness, no time. Two runs write the same bytes to `/output/entry.png`. The image is 1024 by 1024 pixels, PNG, under 1 MiB.
